# Configurações

Abra pela **engrenagem** na barra lateral ou com [[Ctrl+,]]. As mudanças valem na hora e ficam salvas no navegador.

## Aparência

**Modo:** *Sistema* (segue o sistema operacional), *Claro* ou *Escuro*. O botão de sol/lua na barra lateral, ou
[[T]], alterna rapidamente entre claro e escuro.

**Tema:** seis paletas, cada uma com versão clara e escura.

| Tema | Estilo |
| --- | --- |
| Índigo | O padrão: neutro e frio, com destaque roxo-azulado |
| Oceano | Tons de azul |
| Floresta | Tons de verde |
| Sépia | Fundo creme, parecido com papel — bom para leituras longas |
| Rosa | Destaque em rosa |
| Grafite | Preto e branco, sem cor de destaque |

## Leitura

| Opção | Valores |
| --- | --- |
| Tamanho do texto | Pequeno, Médio, Grande, Enorme |
| Fonte | Sem serifa, Serifada, Mono |
| Espaçamento entre linhas | Compacto, Normal, Amplo |
| Largura do conteúdo | Estreita, Normal, Larga, Total |

O painel tem uma **prévia** para você ajustar sem sair dele.

## Interface

- **Índice da página** — mostra ou esconde o "Nesta página".
- **Barra de progresso** — a linha no topo do documento.
- **Lembrar posição de leitura** — retoma cada documento de onde você parou.
- **Modo foco** — esconde a barra lateral ([[F]]).
- **Reduzir animações** — desliga transições e rolagem suave.

## Código

- **Quebrar linhas longas** — evita a rolagem horizontal nos blocos de código.

## Seus dados

Configurações, favoritos e histórico ficam **só neste navegador** — nada é enviado a servidor algum.

- **Exportar** baixa um arquivo `.json` com tudo.
- **Importar** restaura esse arquivo, por exemplo em outro computador.
- **Apagar todos os dados** limpa tudo e volta ao padrão.

:::tip Restaurar padrões
O botão **Restaurar padrões**, no rodapé do painel, volta só as configurações ao padrão — favoritos e histórico são
mantidos.
:::
